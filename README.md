# 3skeng-prawn

The [Prawn](https://github.com/prawnpdf/prawn) PDF library with its dependencies
[pdf-core](https://github.com/prawnpdf/pdf-core) and [ttfunk](https://github.com/prawnpdf/ttfunk),
as modified for embedding in the SHK 3skeng SketchUp extension.

This is not a maintained fork. It exists so that the modified source is freely
available, as the licence conditions ask. For your own projects, use the
original libraries.

| Library | Based on | Licence file |
|---|---|---|
| Prawn | 2.5.0 | `LICENSE.txt` |
| pdf-core | 0.10.0 | `pdf/LICENSE.txt` |
| ttfunk | 1.8.0 | `ttfunk/LICENSE.txt` |

`THIRD_PARTY_NOTICE.txt` lists the licence terms used and the modifications.
